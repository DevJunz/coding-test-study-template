### 등록 방법

1. `_TEMPLATE.md` 복사 → `<깃허브ID>.md`
2. 내용 작성
3. 위 표에 한 줄 추가
4. 커밋: `docs: <깃허브ID> 자기소개 추가`

새 멤버가 합류하면 [`.github/workflows/auto-assign-reviewer.yml`](../.github/workflows/auto-assign-reviewer.yml)의 `members` 배열도 함께 갱신해야 리뷰어 로테이션에 포함됩니다.
