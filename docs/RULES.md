# 📜 스터디 규칙

> 이 규칙은 스터디 시작 전 **전원 동의** 후 확정합니다. 숫자(벌금·기준)는 조정 가능하며, 변경 시 PR로 기록을 남깁니다.

---

## 1. 기간 & 목표

- **기간**: 총 **12주 (약 3개월)**
- **주간 목표 (= "1번 목표")**: 매주 지정된 알고리즘 주제로
  - **⭐ 권장 2문제** (공통·쉬운 코어, 모두가 같은 문제) — **반드시**
  - **🎒 선택 5문제** (같은 유형이면 **플랫폼·레벨 자유** — 프로그래머스·백준·SWEA·LeetCode 등) — 매일 꾸준함용
  - → **총 7문제 ≈ 하루 1문제** 페이스
- 모든 풀이는 **5요소 작성 + PR 머지**까지 완료해야 인정됩니다.
- **권장 학습량**: 하루 약 1~2시간 (5번 참고)

한 주의 마감은 **매주 일요일 23:59** 입니다. (시작 요일은 첫 모임에서 확정)

---

## 2. 💰 보증금 & 벌금

### 보증금
- 시작 시 **1인 30,000원** 예치 → 총무가 공동 관리
- **도중 하차 시 남은 보증금은 반환하지 않습니다.** (3번 참고)

### 벌금 — 하이브리드 방식 (매주 마감 기준)

**A. 권장 문제 (코어 · 낙오 방지)**
| 권장 완료 | 벌금 |
|:---:|:---:|
| 2개 | **0원** ✅ |
| 1개 | **3,000원** |
| 0개 | **6,000원** |

**B. 선택 문제 (매일 꾸준함 · 최소선)**
| 선택 완료 | 추가 벌금 |
|:---:|:---:|
| 3개 이상 | **0원** ✅ |
| 3개 미만 (0~2개) | **+2,000원** |

- **선택 문제는 목표가 5개**지만, 벌금은 **3개 미만일 때만** 부과해 여유를 둡니다. (5개를 다 못 채워도 3개만 넘기면 추가 벌금 없음)
- **주간 최대 벌금 = 6,000 + 2,000 = 8,000원.**
- 예) 권장 2 + 선택 4 → **0원** / 권장 2 + 선택 1 → **2,000원** / 권장 1 + 선택 0 → **5,000원** / 권장 0 + 선택 0 → **8,000원**
- 벌금은 **예치한 보증금에서 차감**합니다.
- **보증금 소진 시**: 잔액이 0원이 되면 다음 주 시작 전까지 **재충전**해야 참여를 이어갈 수 있습니다. 재충전하지 않으면 **자동 하차**로 간주합니다.

> 💡 **지각 제출(마감 후 제출)** 기본값: 벌금 대상이나, 다음 주 마감 전 보충 시 벌금의 절반만 부과 — 첫 모임에서 확정하세요.

## 3. 🚪 하차 & 보증금 처리

- **하차 = 그 시점의 남은 보증금 전액 미반환.**
- 미반환 보증금과 누적 벌금은 다음 중 첫 모임에서 정한 방식으로 처리합니다.
  - (A) **완주자에게 균등 분배** — 끝까지 한 사람에게 보상
  - (B) **종강 회식/모임 비용**으로 사용
  - (C) 완주 순위/점수에 따라 **차등 분배**
- 불가피한 사정(장기 입원 등)에 대한 예외는 **전원 합의**로만 인정합니다.

---

## 4. ✅ 인증 방법

풀이 1건은 다음을 **모두** 만족해야 "완료"로 인정합니다.

1. 정해진 폴더에 파일 생성: `studies/week-XX/<깃허브ID>/...`
2. [문제 풀이 템플릿](../templates/SOLUTION_TEMPLATE.md)의 **5요소를 모두 작성**
   - 접근 방법 / 시간 복잡도 / 공간 복잡도 / 핵심 풀이 방법 / 실제 코드
3. **PR 생성 → 리뷰 1명 이상 → 머지** (마감 전까지)
4. 커밋/PR은 [정해진 템플릿](../.github/PULL_REQUEST_TEMPLATE.md)을 따를 것

> "코드만 복붙"은 인정하지 않습니다. **5요소 서술이 핵심**입니다. 권장·선택 모두 동일하게 5요소를 작성합니다.

## 5. ⏱️ "하루 1~2시간" 은 어떻게 설정하나?

> 시간은 직접 측정할 수 없으므로 **결과물(=푼 문제 수 + 커밋)** 으로 대체합니다. 이번 스터디는 **주 7문제 구조 자체가 "매일 조금씩"의 장치**입니다.

### 구조가 곧 습관
- 하루 1~2시간 ≈ **하루 1문제**. 주 7문제(권장 2 + 선택 5)를 요일에 나눠 풀면 자연스럽게 매일 학습이 됩니다.
- 권장 2문제는 **쉬운 난이도**라 아무도 낙오하지 않게, 선택 5문제는 **자기 레벨**이라 부담 없이 꾸준함을 만듭니다.

### 벌금이 주는 최소한의 강제 (2번 하이브리드)
- **권장 2문제**: 못하면 벌금 → 코어는 반드시.
- **선택 문제**: **주 3개 미만이면 +2,000원** → "매일 조금씩"에 최소한의 책임감. (5개는 목표, 3개는 하한)

### 잔디 & 회고로 독려 (벌금 아님)
- 주 3일 이상 커밋(잔디)을 권장하고, **매주 회고에서 잔디·문제 수를 공유**해 사회적 책임감을 더합니다.

## 6. 🔁 주간 사이클

| 요일 | 할 일 |
|:---|:---|
| 월 | 이번 주 주제/권장·선택 문제 확인 (`studies/week-XX/README.md`) |
| 화~토 | 권장 2 + 선택 5문제 풀이, 수시로 커밋/PR |
| 일 23:59 | **마감** — 이 시점 기준 미머지 PR은 미완료로 집계 |
| 일 or 월 | **주간 회고** (10~20분): 완료 현황(권장·선택 수) 공유, 벌금 집계, 다음 주 예고 |

---

## 7. 리뷰 문화

- PR에는 **최소 1명 이상의 리뷰(👍 또는 코멘트)** 후 머지.
- 리뷰는 지적이 아니라 **배움의 기회**: "나는 이렇게 풀었다", "이 부분 시간복잡도 확인!" 등 가볍게.
- 서로의 풀이를 보며 **다른 접근법**을 배우는 것이 이 스터디의 핵심 가치입니다.

---

## 8. 규칙 변경

- 규칙 변경은 **PR + 전원(또는 과반) 동의**로만 확정합니다.
- 변경 이력은 이 문서의 수정 커밋으로 남깁니다.
