## 1. 접근 방법
큐 사용해서 돌리면서 어떻게 16진수를 int로 변환할지가 핵심이다. 함수 사용 법만 알면 d2 수준이라고 생각함



## 2. 시간 복잡도
**O(N²)** — 회전을 N번 수행하고, 매 회전마다 한 변(길이 N/4)을 읽고 되돌리는 연산이 0.5N이다. 즉 반복당 O(N)이 N회 반복되어 **O(N²)**. (0.5N은 한 번의 반복 내부 비용이라 전체엔 바깥 N회를 곱해야 한다.)

## 3. 공간 복잡도

**O(N)** — 큐 크기

## 4. 핵심 풀이 방법 ⭐
- 이번에는 임시 변수를 사용해서 popleft + append()로 돌렸다.
- 그리고 N//4를 한 변의 길이로 만들었다.
- join + int 함수의 조합으로 16진수 문자열을 int로 바꿨다.
- 아직 int_list에 저장되지 않은 값인 경우에만 넣어서 역정렬



## 5. 실제 코드
<!-- 통과한 코드. 언어 태그를 정확히 표기하세요. -->

```python
T = int(input())
from collections import deque
for t in range(1,T+1):
    N,K = map(int,input().split())
    num_len = N//4
    
    value = input()
    q = deque(value)
    int_list = []

    for _ in range(N):
        cand = []
        for _ in range(num_len):
            cand.append(q.popleft())
        cand_int = int(''.join(cand),16)
        if cand_int not in int_list:
            int_list.append(cand_int)
        for _ in range(num_len):
            tmp = cand.pop()
            q.appendleft(tmp)
        
        
        tmp = q.popleft()
        q.append(tmp)

        
    int_list.sort(reverse=True)
    print(f"#{t} {int_list[K-1]}")
```
