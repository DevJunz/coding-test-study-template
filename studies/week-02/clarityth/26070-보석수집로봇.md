## 1. 접근 방법
<!-- 문제를 어떻게 이해했고, 왜 이 전략을 택했는지. 처음 떠올린 방법과 막혔던 지점도 좋음. -->
* (0, 0)에서 오른쪽 방향(→)으로 출발하여 1~M번 보석을 순서대로 수집하는 최소 회전 횟수 구하기
* 위치 외에 방향과 목표 보석 번호를 포함한 4차원 상태 `(d, row, col, target_j)` 정의
* 로봇의 행동을 **[보석 획득]**, **[제자리 우회전]**, **[직진 이동]** 3가지로 분리하여 다익스트라(Priority Queue) 탐색 적용


## 2. 시간 복잡도
<!-- 예: O(N log N) — 정렬 O(N log N) + 순회 O(N). 근거를 함께 적기. -->
<!-- SWEA는 시간 제한이 빡빡한 문제가 많으니 반드시 따져볼 것! -->
**케이스당 O((V + E) log V) = O(N² · M · log(N² · M))**
* **상태 수 (V)**: 최대 $10 \times 10 \times 4 \times 10 = 4,000$개
* 상태당 간선은 최대 3개이므로 `E ≤ 3V`
* 전체 입력 기준 복잡도는 `O(T · N² · M · log(N² · M))`

## 3. 공간 복잡도
<!-- 예: O(N) — 방문 배열 N개. -->
**O(N² · M)** —
* `dist` 딕셔너리 및 `pq` 힙 저장 공간 ($O(N^2 \cdot M)$)


## 4. 핵심 풀이 방법 ⭐
<!-- 이 문제의 결정적 아이디어 / 자주 하는 실수 / 알아야 할 개념. 가장 중요한 항목! -->
1. **4차원 상태 확장**:
   - `(d, row, col, target_j)` 튜플 정의 후  `dist` 딕셔너리로 최단 회전수 기록
2. **동작의 분리**:
   - **보석 획득**: `target_j + 1` 갱신 후 `continue` (회전 +0)
   - **제자리 우회전**: `nd = (d + 1) % 4`, 위치 유지 (회전 +1)
   - **직진 이동**: `row + dy[d], col + dx[d]` (회전 +0)
3. **시계 방향 오프셋 배열**:
   - `dx = [1, 0, -1, 0]`, `dy = [0, 1, 0, -1]` (0:우, 1:하, 2:좌, 3:상)로 설정하여 `(d + 1) % 4` 우회전 처리


## 5. 실제 코드
<!-- 통과한 코드. 언어 태그를 정확히 표기하세요. -->

```python
import heapq

T = int(input())

# 0: 우, 1: 하, 2: 좌, 3: 상 (시계 방향)
dx = [1, 0, -1, 0]
dy = [0, 1, 0, -1]

for test_case in range(1, T + 1):
    N = int(input())
    grid = [list(map(int, input().split())) for _ in range(N)]

    jewels = {}
    j_idx = 1
    for i in range(N):
        for j in range(N):
            if grid[i][j] > 0:
                jewels[grid[i][j]] = (i, j)
                j_idx += 1

    # dist[(방향, 행, 열, 목표 보석 번호)] = 최소 회전 횟수
    dist = {}
    dist[(0, 0, 0, 1)] = 0

    ans = float("inf")

    # 힙 원소: (회전 횟수, 방향, 행, 열, 목표 보석 번호)
    pq = [(0, 0, 0, 0, 1)]

    while pq:
        rotate, d, row, col, target_j = heapq.heappop(pq)

        # 더 적은 회전수로 방문한 상태면 스킵
        if rotate > dist.get((d, row, col, target_j), float("inf")):
            continue

        # 보석 획득
        if (row, col) == jewels.get(target_j):
            next_target = target_j + 1

            if next_target == j_idx:
                ans = rotate
                break

            # 보석 번호 증가
            if rotate < dist.get((d, row, col, next_target), float("inf")):
                dist[(d, row, col, next_target)] = rotate
                heapq.heappush(pq, (rotate, d, row, col, next_target))
            continue

        # 회전
        nd = (d + 1) % 4
        if (rotate + 1) < dist.get((nd, row, col, target_j), float("inf")):
            dist[(nd, row, col, target_j)] = rotate + 1
            heapq.heappush(pq, (rotate + 1, nd, row, col, target_j))

        # 직진
        n_r, n_c = row + dy[d], col + dx[d]
        if 0 <= n_r < N and 0 <= n_c < N:
            if rotate < dist.get((d, n_r, n_c, target_j), float("inf")):
                dist[(d, n_r, n_c, target_j)] = rotate
                heapq.heappush(pq, (rotate, d, n_r, n_c, target_j))

    print(f"#{test_case} {ans}")
```
