## 1. 접근 방법
<!-- 문제를 어떻게 이해했고, 왜 이 전략을 택했는지. 처음 떠올린 방법과 막혔던 지점도 좋음. -->
* 처음엔 permutations 이용해 블록을 고르는 경우를 모두 계산하려했지만, 
* 순차적으로 먼저 제거할 블록을 고르면 남은 블록들이 인접하게 변해 경우의 수가 $N!$로 폭발하고 상태 관리가 어려워짐
* **역발상 (구간 DP)**: 특정 구간 `[start, end]`에서 가장 마지막에 제거할 블록 $k$를 기준으로 생각
* $k$번째 블록이 해당 구간에서 제일 마지막으로 제거된다면, $k$의 좌/우 이웃은 항상 구간 외부인 `blocks[start - 1]`과 `blocks[end + 1]`로 고정
* 따라서 `dp[start][end]`를 `[start, end]` 구간의 블록을 모두 제거할 때 얻는 최대 점수로 정의하고 메모이제이션(Top-Down DP)을 적용


## 2. 시간 복잡도
<!-- 예: O(N log N) — 정렬 O(N log N) + 순회 O(N). 근거를 함께 적기. -->
<!-- SWEA는 시간 제한이 빡빡한 문제가 많으니 반드시 따져볼 것! -->

**O(N³)** —
* **구간 상태 개수**: $0 \le start \le end < N$ 인 구간의 개수 $O(N^2)$.
* **전이(Transition) 연산**: 각 구간마다 $k$를 $start \sim end$ 범위로 탐색하며 $O(N)$번 비교
* **총 시간 복잡도**: $O(N^2) \times O(N) = O(N^3)$ (N <= 10)


## 3. 공간 복잡도
<!-- 예: O(N) — 방문 배열 N개. -->

**O(N²)** —
* `dp[N][N]` 2차원 메모이제이션 배열 생성 $O(N^2)$
* 재귀 호출 스택 깊이 최대 $O(N)$


## 4. 핵심 풀이 방법 ⭐
<!-- 이 문제의 결정적 아이디어 / 자주 하는 실수 / 알아야 할 개념. 가장 중요한 항목! -->
1. **마지막에 제거될 블록 기준의 구간 DP (Interval DP)**:
   - "첫 번째로 깰 블록"을 고르면 남은 양옆 요소가 가변적이지만, "해당 구간에서 마지막으로 깰 블록 $k$"를 고르면 좌우 이웃이 고정되어 좌측 구간 `[start, k-1]`과 우측 구간 `[k+1, end]`로 분할 가능
2. **경계 처리 (`left_val`, `right_val`)**:
   - $k$가 맨 마지막에 깨질 때 이웃 블록은 `start - 1`과 `end + 1` 위치
   - 구간이 배열 양 끝 경계 밖인 경우(-1) 예외 처리
3. **Top-Down 메모이제이션**:
   - `dp[start][end]`에 계산된 최댓값을 저장


## 5. 실제 코드
<!-- 통과한 코드. 언어 태그를 정확히 표기하세요. -->

```python

T = int(input())

for test_case in range(1, T+1):
    N = int(input())
    blocks = list(map(int, input().split()))

    if N == 1:
        print(f"#{test_case} {blocks[0]}")
        continue

    dp = [[-1] * N for _ in range(N)]

    def get_max_score(start, end):
        if start > end:
            return 0

        # DP 메모이제이션
        if dp[start][end] != -1:
            return dp[start][end]

        max_val = -float('inf')

        # [start, end] 구간에서 마지막으로 깨트릴 블록 k 탐색
        for k in range(start, end+1):
            left_val = blocks[start - 1] if start > 0 else -1   # 좌측 이웃
            right_val = blocks[end + 1] if end < N - 1 else -1  # 우측 이웃

            if left_val == -1 and right_val > 0:       # 왼쪽 끝일 경우
                score = right_val
            elif right_val == -1 and left_val > 0:     # 오른쪽 끝일 경우
                score = left_val
            elif left_val > 0 and right_val > 0:       # 중간일 경우
                score = left_val * right_val
            elif left_val == -1 and right_val == -1:   # 블록이 오직 하나 남은 경우
                score = blocks[k]

            # top-down DP: 좌측 구간 최댓값 + 우측 구간 최댓값 + 해당 블록 k를 깼을 때 점수
            val = get_max_score(start, k-1) + get_max_score(k+1, end) + score
            max_val = max(max_val, val)

        dp[start][end] = max_val
        return max_val

    print(f"#{test_case} {get_max_score(0, N-1)}")
```
