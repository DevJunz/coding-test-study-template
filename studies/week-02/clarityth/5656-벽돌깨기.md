## 1. 접근 방법
<!-- 문제를 어떻게 이해했고, 왜 이 전략을 택했는지. 처음 떠올린 방법과 막혔던 지점도 좋음. -->
* 구슬을 $N$번 떨어뜨려 맞출 수 있는 모든 위치(열 $W$개)의 경우의 수를 DFS 백트래킹 탐색
* 구슬을 쏠 열(`col`)을 결정하면, 해당 열에서 가장 상단에 있는 벽돌을 타격하여 연쇄 폭발 처리
* 폭발이 완료된 후 남아있는 벽돌들을 아래로 떨어뜨리는 중력 처리를 수행한 뒤 다음 단계로 재귀 호출
* 매 단계마다 남아있는 벽돌 수의 최솟값을 갱신하여 $N$번 구슬을 모두 쏜 뒤 남은 벽돌의 최소 개수 계산


## 2. 시간 복잡도
<!-- 예: O(N log N) — 정렬 O(N log N) + 순회 O(N). 근거를 함께 적기. -->
<!-- SWEA는 시간 제한이 빡빡한 문제가 많으니 반드시 따져볼 것! -->

**O(W^N · H · W)** —
* **구슬 투하 경우의 수**: 총 $N$번 구슬을 쏘며 $W$개 열 중 하나를 선택하므로 $W^N$가지 상태 탐색. $W=12, N=4$일 때 실제 DFS 간선 수는 $W + W^2 + W^3 + W^4 = 22,620$개.
* **단계별 연산**: 각 간선마다 보드 복사, 폭발(최대 $H \times W$) 및 중력 처리($O(H \times W)$) 진행.


## 3. 공간 복잡도
<!-- 예: O(N) — 방문 배열 N개. -->

**O(N · H · W)** —
* **재귀 호출 스택**: DFS 깊이 최대 $N$개.
* **보드 복사**: 매 재귀 단계마다 $H \times W$크기의 `next_board` deepcopy ($N \times H \times W$).


## 4. 핵심 풀이 방법 ⭐
<!-- 이 문제의 결정적 아이디어 / 자주 하는 실수 / 알아야 할 개념. 가장 중요한 항목! -->
1. **DFS 백트래킹과 매 단계 최솟값 갱신**:
   - `ans = min(ans, remain)`을 DFS 첫 줄에 배치하여 항상 결과 값을 업데이트 했어야 했는데, 최초 풀이시 DFS의 depth가 N일때만 업데이트하도록 잘못 설정
2. **연쇄 폭발 처리**:
   - 벽돌의 숫자 K를 먼저 따로 보관한 뒤 해당 위치를 `0`으로 지우고, 상하좌우 dx, dy에 대해 K-1 범위만큼 연쇄 폭발을 재귀함수로 구현 (BFS 큐로도 구현 가능)
3. **중력 정렬**:
   - 각 열을 위에서부터 순회해 `0`이 아닌 벽돌을 모은 후, `pop()`으로 바닥부터 채워 넣어 벽돌을 아래로 이동
4. **가지치기**:
   - `ans == 0`이 되는 순간 이미 도달 가능한 최댓값이므로 조기 종료


## 5. 실제 코드
<!-- 통과한 코드. 언어 태그를 정확히 표기하세요. -->

```python
T = int(input())

dx = [0, 0, -1, 1]
dy = [-1, 1, 0, 0]

for test_case in range(1, T+1):
    N, W, H = map(int, input().split())

    board = [list(map(int, input().split())) for _ in range(H)]

    def get_brick_cnt(board):
        cnt = 0
        for row in board:
            for room in row:
                if room > 0:
                    cnt += 1
        return cnt

    def boom(row, col, board):
        power = board[row][col]
        board[row][col] = 0
        cnt = 1

        for p in range(1, power):
            for i in range(4):
                nr, nc = row + p * dy[i], col + p * dx[i]
                if 0 <= nr < H and 0 <= nc < W:
                    if board[nr][nc] > 1:
                        cnt += boom(nr, nc, board)
                        board[nr][nc] = 0
                    elif board[nr][nc] == 1:
                        board[nr][nc] = 0
                        cnt += 1
        return cnt

    def gravity(board):
        for col in range(W):
            temp = []
            for row in range(H):
                if board[row][col] > 0:
                    temp.append(board[row][col])
                board[row][col] = 0

            row = H - 1
            while temp:
                board[row][col] = temp.pop()
                row -= 1

    def dfs(depth, board, remain):
        global ans

        ans = min(ans, remain)

        if depth == N or ans == 0:
            return

        for col in range(W):
            for row in range(H):
                if board[row][col] > 0:
                    next_board = [r[:] for r in board]
                    crashed = boom(row, col, next_board)
                    gravity(next_board)
                    dfs(depth + 1, next_board, remain - crashed)
                    break

    ans = get_brick_cnt(board)
    dfs(0, board, ans)
    print(f"#{test_case} {ans}")
```

### 🧠 회고 (선택)
<!-- 배운 점, 비슷한 유형에서 재사용할 아이디어, 리뷰어에게 묻고 싶은 점 -->
* 최초 풀이시, product를 이용해 풀었는데 너무 오래걸려 수정했다.
* dfs의 호출에 따른 board의 상태 관리를 deepcopy로 각각 전달하는 게 중요했다.
* 연쇄 폭발 로직을 구현하는데 있어서 큐를 이용하는 방법이 있다는 것을 알게 되었다.
